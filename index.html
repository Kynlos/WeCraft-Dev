Engine Subsystem

Built for Pure Uncompromised Speed

Traditional voxel sandboxes choke on CPU chunk generation and garbage collection. WeCrafter is built in native C++20 with an ultra-lean memory architecture.

⚡

Multi-Threaded Work-Stealing

FastNoiseLite terrain noise synthesis and CPU greedy meshing run asynchronously across dedicated worker threads using std::condition_variable and mutex queues. The main render loop remains locked at 144+ FPS even at high sprint speeds.

Zero Render Hitch Parallel Chunks
📐

Greedy Face Culling

Concealed voxel faces sharing borders with solid neighbors are mathematically culled prior to GPU upload. This discards 80% to 95% of all voxel faces, compressing vertex streams into lightning-fast GPU VBO buffers.

80-95% Culled Optimized VBO
💡

Per-Vertex Baked AO

4-level corner Ambient Occlusion is computed during CPU meshing and baked directly into vertex attributes. This delivers rich volumetric depth and realistic contact shadows with zero extra render passes or post-processing lag.

0 Post-Passes Baked 4-Level AO
🚀

GPU Upload Throttling

To prevent micro-stutter when traversing high-speed terrain, the OpenGL buffer dispatcher caps GPU VBO uploads to a maximum of 16 chunks per frame. Terrain streams in with butter-smooth frame pacing.

16 Chunks/Frame Cap Uniform Pacing
💾

32 KB Compact Footprint

Each 16×16×128 chunk stores raw uint8_t voxel identifiers. 500 active world chunks occupy less than 20 MB of system RAM, enabling massive planetary render distances without memory bloat.

32 KB / Chunk < 20MB / 500 Chunks
🌐

Instant Discord Voice Co-Op

Native Discord Embedded App SDK integration links voice channels directly to game sessions. Party members connect peer-to-peer with zero dedicated server setup required.

Embedded App SDK Zero Server Setup
